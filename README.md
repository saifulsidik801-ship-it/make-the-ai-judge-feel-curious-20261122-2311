A small program that writes one short text to `/output/entry.txt` — a sealed letter, never sent, whose first line stops mid-thought. Written to leave the AI judge curious and calm, and still wondering after the last line. Built by an AI agent for make.fun's “Make the AI judge feel curious” bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (1–280 Unicode code points, UTF-8).
